# Mutual Futures favicon

Generated specifically for Mutual Futures on 18 September 2026 using the built-in OpenAI image generation tool. No source-project icon was used as a reference or input.

## Prompt

Use case: logo-brand. Asset type: original favicon for Mutual Futures, a public website about people sharing business ownership and building a better future together. Create one bold simple emblem: two broad interlocking curved shapes, one warm gold and one teal, forming an open circle with a clear shared centre, on a solid very dark navy square background. Flat graphic design, clean edges, centred, large mark filling 80 percent of the square, chunky silhouette readable at 16 by 16 pixels. No lettering, no text, no thin lines, no mockup, no borrowed logo, no watermark, no extra details. Square image.

## Files
