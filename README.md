# Mutual Futures

**From business succession to mutual wealth, universal intelligence and more possible lives.**

A public, multi-page workbench by Luke Nathan Hayes / Strange But True / Aura of Intelligence. It connects voluntary succession of existing staffed businesses with member ownership, upgrading, Try Everything Once, Intermittent Retirement, universal intelligence and universal adequate income, legal reflection and radical overcompliance, civic health research, existential resilience, world travel and Kardashev galactic games.

**Public page:** https://auraofintelligence.github.io/mutual-futures/

**Repository:** https://github.com/auraofintelligence/mutual-futures

This is a standalone project. It does not replace the main Aura website. The first complete build is being prepared in this repository; deployment status is recorded by GitHub Actions rather than claimed here in advance.
